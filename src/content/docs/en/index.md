This site is for the six of us. It has one purpose: to make every team member able to **explain and defend any part** of our Linear Algebra project, *Image Processing Using Matrices*, in front of the professor.

You do not need to know Python. The professor's questions will be mostly about the maths, so the site teaches the maths first and shows the code only as "the maths written for a computer".

## Where to start

1. Read [What is the project?](/en/01-start/what-is-the-project/).
2. Then read [How to use this site](/en/01-start/how-to-use-this-site/).
3. Follow the stages in the sidebar, in order.

## The core idea

Every digital image is a matrix of numbers. So the things we do to an image (make it gray, brighter, mirrored, or black and white) are matrix operations.
