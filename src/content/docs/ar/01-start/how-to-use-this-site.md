## مسار المذاكرة

امشي ورا المراحل في القايمة الجانبية بالترتيب ده:

| المرحلة | هتتعلم إيه |
| --- | --- |
| 1. ابدأ من هنا | إيه هو المشروع وإزاي تستخدم الموقع |
| 2. الصور مصفوفات | المصفوفة (matrix)، والبكسل، وقنوات اللون، و`uint8` |
| 3. الجبر الخطي اللي بنستخدمه | المتجهات (vectors)، والضرب النقطي (dot product)، وضرب مصفوفة في متجه وفي مصفوفة، ومصفوفة الوحدة (identity)، والمنقولة (transpose)، والمعكوس (inverse)، والمصفوفتين $E$ و$J$ |
| 4. العمليات الأربعة | لكل عملية: المعادلة، ومثال محلول، والخواص، والأسئلة المتوقعة |
| 5. نجمّع الكل مع بعض | ترتيب العمليات، وأنهي عمليات تتبادل (commute)، وتحويلات تانية |
| 6. قراءة الكود كرياضيات | الـ NumPy اللي محتاجه بس |
| 7. اتبنى إزاي | GitHub وVercel باختصار |
| 8. دافع عنه | بنك الأسئلة بإجاباتها، وسكربتات الدقيقة الواحدة، وفخاخ "طب لو"، واختبارات، وقاموس |

## القاعدة الذهبية

**اشرح الرياضيات الأول، وبعدين وريه سطر الكود اللي بينفذها.** الكود هو نفس الرياضيات بس مكتوبة بلغة الكمبيوتر.

## إزاي تذاكر صفحة واحدة

1. اقرأ الصفحة مرة واحدة ببطء.
2. حُل كل مثال محلول بإيدك بالقلم، من غير ما تبص على الإجابة.
3. اقفل الصفحة وقول الفكرة بصوت عالي بكلامك.
4. جاوب أسئلة "جرّب نفسك" اللي في الآخر.

لو قدرت تعمل الخطوة 3 في حوالي دقيقة، يبقى إنت جاهز للموضوع ده.

## الرموز المستخدمة في كل مكان

| الرمز | معناه |
| --- | --- |
| $H$ و$W$ | ارتفاع وعرض الصورة بالبكسل. دول عدد الصفوف وعدد الأعمدة. |
| $I$ | مصفوفة الصورة، زي ما في التقرير. $I(i,j)$ هو العنصر في الصف $i$ والعمود $j$. |
| $R$ و$G$ و$B$ | مصفوفات الأحمر والأخضر والأزرق في الصورة الملونة. |
| $p$ | بكسل واحد في الصورة الملونة، المتجه $(R, G, B)$. |
| $w$ | متجه الأوزان $(0.299,\ 0.587,\ 0.114)$ المستخدم في الرمادي. |
| $\beta$ | إزاحة السطوع (رقم، موجب أو سالب). |
| $T$ | الحد الفاصل (threshold) للأبيض والأسود (الافتراضي 128). |
| $E$ | مصفوفة كلها واحدات. |
| $J$ | مصفوفة التبديل (واحدات على القطر الثانوي). |
| $\mathrm{Id}$ | مصفوفة الوحدة (identity matrix). |
| $A^T$ | منقولة $A$ (transpose). |

:::note
في التقرير بتاعنا الحرف $I$ مستخدم للصورة ولمصفوفة الوحدة مع بعض. في الموقع ده **الصورة هي $I$** و**مصفوفة الوحدة هي $\mathrm{Id}$**، عشان الاتنين ميتلخبطوش.
:::

## العربي والإنجليزي

استخدم قايمة اللغة اللي فوق في الصفحة. بتفتحلك نفس الصفحة باللغة التانية.

- اللغتين فيهم نفس الصفحات بنفس الترتيب.
- في العربي، المعادلات والكود بتتكتب برضه من الشمال لليمين، والأرقام بالأرقام 0 لـ 9 بالظبط زي الكود والتقرير.
- الشرح بالعربي بكلام مصري بسيط، والمصطلح الرياضي المعتمد بييجي الأول وجنبه المصطلح الإنجليزي بين قوسين.
